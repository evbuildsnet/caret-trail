# Demo assets

The README demo is a real screen recording of Caret Trail in TextEdit on macOS,
recorded on September 22, 2026. It uses the default **120 ms** duration and the
Mac's blue accent color. Playback is at the original speed.

- **0–6 s:** move across words and jump along the line.
- **6–10 s:** move vertically down the paragraphs.
- **10–15 s:** jump diagonally between the ends of long and short paragraphs.
- **15–16.3 s:** return to the starting position for the loop.

The recording was trimmed, cropped to the document, and given a dark border.
The caret and its trail are captured pixels; the animation was not recreated.

`caret-trail-demo.mp4` is the 1280 × 760, 60 fps H.264 version (about 400 KB).
`caret-trail-demo.gif` is the 960 × 570, 50 fps looping README preview (about 3.3 MB).
Both are 16.3 seconds long. `demo-text.rtf` is the document used for the recording.
